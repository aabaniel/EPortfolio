# Aaron Abaniel — React portfolio

A responsive static React/Vite recreation based on the supplied screenshots.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Replace the `your photo` block in `src/main.jsx` with your own image.
- Update the links, email, education, experience, projects, and achievements arrays.
- Main colors are defined at the top of `src/styles.css`:
  - `--bg`: dark brown background
  - `--gold`: orange/gold accent
  - `--gold-dark`: darker gold text
  - `--cream`: off-white headline/body text

The layout is responsive and uses a sticky section navigation bar on smaller screens.
